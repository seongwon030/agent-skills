# kickoff

코드를 쓰지 않는다. 이 스킬의 산출물은 `AGENTS.md` 하나다.

## 순서

1. `README.md`와 과제 안내를 읽고, 요구사항을 **내 말로** 3줄 이내로 다시 쓴다. 안내에 없는 것은 "가정"으로 분리해 표시한다.
2. 완료 기준을 측정 가능하게 쓴다. 예: "입력 X에 출력 Y", "`GET /health` 200".
3. 제약을 적는다: 언어·라이브러리, 입력 범위, 보안, 실행 환경.
4. 작업을 3~6단계로 나눈다. 단계마다 산출물과 **검증 방법(실행할 명령 또는 케이스)** 을 적는다.
5. 가정과 모르는 것을 목록으로 내고 **멈춘다**. 사용자가 답하거나 고치기 전에 구현으로 넘어가지 않는다.
6. 사용자가 고친 내용을 반영해 `AGENTS.md`를 확정한다. 고친 이유는 "가정과 모르는 것" 아래에 한 줄씩 남긴다.
7. `docs: 목표·제약·작업분해 확정`으로 커밋한다.

`AGENTS.md`가 이미 있고 과제 쪽 내용이 들어 있으면 지우지 않는다. 그 아래에 위 절들을 추가한다.

## 금지

- 계획 단계에서 파일 생성·의존성 설치
- 안내에 없는 요구사항을 가정 표시 없이 목표에 넣기
- 검증 방법이 비어 있는 단계
